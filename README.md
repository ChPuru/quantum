# Quantum Computing Workspace

This repository contains implementations of various quantum computing algorithms and applications.

## Projects

- **grover-search**: Implementation of Grover's search algorithm
- **qaoa-maxcut**: Quantum Approximate Optimization Algorithm for the MaxCut problem
- **qec-bitflip**: Quantum Error Correction using the Bit Flip Code
- **qkd-bb84**: Quantum Key Distribution using the BB84 protocol
- **qrng**: Quantum Random Number Generator
- **quantum-annealing**: Quantum Annealing simulation
- **quantum-blockchain**: Quantum-enhanced blockchain validation
- **quantum-game-theory**: Quantum game theory demonstration with penny flip game
- **quantum-ml-qnn**: Quantum Neural Network for image classification
- **quantum-secure-storage**: Quantum secure storage system
- **quantum-teleportation**: Quantum teleportation protocol
- **shors-algorithm**: Shor's factoring algorithm
- **vqe-h2**: Variational Quantum Eigensolver for H2 molecule energy calculation
